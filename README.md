## 📌 Overview

**Mission PlusTwo** turns the complete Kerala DHSE Plus Two syllabus and exam deadlines into an adaptive, day-by-day action plan. 

Whether preparing for board exams or managing Plus One improvement papers, it tracks chapter-by-chapter progress and dynamically rebuilds your schedule if you ever fall behind.

---

## ✨ Key Features

- 🎯 **Kerala DHSE Rationalized Syllabus**: Pre-loaded with official topics and chapters for **Physics**, **Chemistry**, **Mathematics**, and **Computer Science**.
- 📅 **Dynamic Day-by-Day Scheduler**: Automatically divides chapters and terms into manageable daily study tasks tailored to your target date.
- 🔄 **One-Click Re-planning**: Fell behind? Open the **Adjust Schedule** modal, pick where you left off, and your remaining syllabus redistributes automatically.
- 📝 **Plus One Improvement Integration**: Dedicated scheduling options to tackle Plus One backlog subjects alongside regular Plus Two coursework.
- 🎉 **Interactive Feedback**: Satisfying check-off animations with **Tone.js** sound effects and celebratory **Canvas Confetti** streaks!
- 💾 **Automatic Local Saving**: All progress is saved automatically to your device via browser LocalStorage.

## 💻 Running Locally

If you prefer to run or modify the application locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sreyasts/intelligent-study-planner-for-plus-two-.git
   ```
2. **Open `index.html`:**
   Double-click `index.html` in your file explorer, or serve it with any local server:
   ```bash
   npx serve .
   ```
