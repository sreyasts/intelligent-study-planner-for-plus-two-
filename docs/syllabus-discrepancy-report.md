## 3. Evidence-Based Study Time Estimation Methodology

Each canonical task is assigned an estimated duration (minutes) derived from:
1. **SCERT Prescribed Class Periods**: SCERT assigns instructional periods (typically 45 minutes each) per unit.
2. **Cognitive Load by Concept Type**:
   - *Abstract Mathematical Derivations* (e.g. Ray Optics lens maker formula, Integrals by parts): ~75–85 minutes.
   - *Reaction Mechanisms / Code Syntax Practice* (e.g. SN1/SN2, PHP MySQL queries): ~65–75 minutes.
   - *Qualitative Theory & Taxonomy* (e.g. Microbes in Human Welfare, ICT and Society): ~50–60 minutes.
3. **Daily Cap Bounds**: The planner balances daily targets to stay within the student's daily study hours (preset default: 3.5 hrs/day, adjustable from 2 to 6 hrs/day).
