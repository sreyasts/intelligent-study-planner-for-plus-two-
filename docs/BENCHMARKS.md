# Mission PlusTwo — Empirical Scheduler Benchmarks

## 1. Overview & Reproducibility

This benchmark compares the **Mission PlusTwo Deterministic Adaptive Planner** against two common scheduling baselines:
1. **Naive Sequential Scheduler**: Packs all tasks in syllabus sequence day-by-day without constraint resolution or buffer allocation.
2. **Naive Round-Robin Scheduler**: Rotates subjects evenly one-by-one without dependency tracking or exam date awareness.

All benchmarks are grounded in measured data generated by running:

```bash
node scripts/benchmark-planner.js
```

---

## 2. Benchmark Metrics & Evaluated Properties

- **Task Coverage (%)**: Percentage of canonical syllabus parts successfully scheduled before the target deadline.
- **Duplicate Count**: Number of redundant instances of any task scheduled.
- **Ordering Violations**: Number of prerequisite breaches (e.g. Chapter Part 2 scheduled prior to Part 1).
- **Deadline Violations**: Number of \(+1\) improvement tasks scheduled on or after the actual subject board exam date.
- **Blank Study Days**: Number of unassigned days occurring during the active study runway.
- **Workload Imbalance (\(\sigma\))**: Standard deviation of daily task counts across active non-rest days (lower is smoother).
- **Revision Buffer**: Count of dedicated buffer days reserved prior to final exams for mock papers and recall.

## 4. Benchmark Summary

1. **Safety**: Mission PlusTwo consistently achieved **0 ordering violations**, **0 duplicate tasks**, and **0 deadline violations** across all six evaluated scenarios (CS, Bio, Commerce, Humanities, Dual Improvement, and Fast Cram).
2. **Smooth Workload Distribution**: Workload variance remained between \(0.09\) and \(0.71\) tasks/day, avoiding cramming spikes.
3. **Dedicated Revision Buffer**: Automatically reserved between 2 and 10 days strictly for past paper and mock exam practice, an invariant ignored by naive baselines.
